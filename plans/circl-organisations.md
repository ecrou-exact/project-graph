*Written 23 September 2026. Status: step 1 to do (generate the OCD files), then steps 2 to 6 (Claude).*

## Goal

The page <https://new.circl.lu/projects/github-organisations/> lists the 22 GitHub
organisations managed or co-managed by CIRCL. It is the single source.

- **Level 1 (done):** one graph with CIRCL in the centre and the 21 other organisations around it,
  each with its logo and GitHub facts (`examples/circl.json`, Graph → CIRCL example in the app,
  `/hugo-example/circl/` in the Hugo example).
- **Level 2 (this plan):** clicking an organisation, **with or without JavaScript**, opens a new
  graph: that organisation and all its projects (its GitHub repositories), with their details.

The source of each level-2 graph is an **Open Contributions Descriptor** (OCD), the file an
organisation publishes at `https://<domain>/.well-known/open-contributions.json`. The files we
generate are real well-known files: each organisation can publish its own later, and it becomes
the official source.

## Step 1 — Generate the OCD files (you, tomorrow)

The OCD repository has the tools: `bin/github-to-ocd.py` (an organisation's repositories → OCD)
and `bin/validator.py` (checks a file against the schema).

**Before starting:** the GitHub API allows 5000 requests an hour per account, shared by every
tool. The script makes a few requests per repository (about 400 repositories in total), so run
it on a fresh hour. Check what is left with `gh api rate_limit --jq .resources.core`.

```bash
# 1. The tools
git clone https://github.com/ossbase-org/Open-Contributions-Descriptor.git ~/Documents/ossBase-org/Open-Contributions-Descriptor
cd ~/Documents/ossBase-org/Open-Contributions-Descriptor
python3 -m venv .venv && . .venv/bin/activate && pip install requests jsonschema

# 2. A token (the one of the gh CLI)
export GITHUB_TOKEN="$(gh auth token)"

# 3. Where the files go
OUT=~/Documents/pivograph/examples/circl-ocd
mkdir -p "$OUT"

# 4. One OCD per organisation: "login domain". Adjust the domains marked "to decide" above.
while read -r org domain; do
  echo "== $org ($domain)"
  existing="https://$domain/.well-known/open-contributions.json"
  if curl -sfL -o /dev/null "$existing"; then
    # Already published (MISP, AIL, Vulnerability-Lookup): keep it, add the missing repositories.
    python3 bin/github-to-ocd.py --org "$org" --domain "$domain" --input "$existing" --merge-projects --output "$OUT/$org.json"
  else
    python3 bin/github-to-ocd.py --org "$org" --domain "$domain" --output "$OUT/$org.json"
  fi
done <<'EOF'
CIRCL circl.lu
MISP misp-project.org
vulnerability-lookup vulnerability-lookup.org
pandora-analysis pandora.circl.lu
lookyloo lookyloo.eu
ail-project ail-project.org
hashlookup hashlookup.io
rulezet rulezet.org
pivotick pivotick.github.io
gcve-eu gcve.eu
cve-search cve-search.org
typosquatter typosquatting-finder.circl.lu
kunai-project why.kunai.rocks
d4-project d4-project.org
ngsoti circl.lu
neolea neolea.github.io
draugnet circl.lu
fanything-project circl.lu
flowintel flowintel.org
cerebrate-project cerebrate-project.org
SkillAegis circl.lu
BinTriage circl.lu
EOF

# 5. Check every file
for f in "$OUT"/*.json; do echo "== $f"; python3 bin/validator.py "$f"; done
```

Check `python3 bin/validator.py --help` first: if it expects other arguments, adjust step 5.

Notes:

- Forks and archived repositories are left out by default (`--include-forks`, `--include-archived` to keep them).
- `--max-repos 5` makes a quick trial run on one organisation before the whole loop.
- The organisations without a website get `circl.lu` in the loop above; change it if you decide otherwise.
- BinTriage has no public repository: its file will list no project.
